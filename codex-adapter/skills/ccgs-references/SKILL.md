# CCGS References

This support skill exists so local Codex installs can carry the original CCGS reference files.

Load files from `references/agents/`, `references/agent-memory/`, `references/docs/`, `references/source-skills/`, `references/skill-testing-framework/`, `references/rules/`, `references/hooks/`, `references/hook-config.json`, or `references/statusline.sh` only when a workflow explicitly needs that detail.
